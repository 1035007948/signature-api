#构建一个签名和验签接口项目
新建一个项目，项目名称signature-api。
项目功能如下：
1、签名接口：用于对请求进行签名，签名结果返回给客户端。签名信息和签名结果存储在数据库和缓存中。
2、验签接口：用于对客户端发送的签名进行验签，返回验签结果。
#创建项目要求：
1、使用java语言,JDK选用1.8。
2、使用springboot框架实现RESTful接口输出。
3、使用mysql数据库存储签名信息和签名结果。
4、使用redis缓存签名结果。
5、使用springboot的自动配置功能，无需手动配置。
6、使用springboot的测试功能，生成测试类。
7、集成swagger2，生成接口文档。
8、生成项目文档、代码注释、接口文档、SQL部署脚本。
